# Media

The published images are faithful crops of photographs taken from a physical
Nokia E71. They were resized and stripped of camera metadata; no screen or
device content was generated or retouched.

| File              | Content                        |
| ----------------- | ------------------------------ |
| `hero-phone.jpg`  | W4ME Station cartridge library |
| `sokoban.jpg`     | Sokoban title screen           |
| `wasm-wars.jpg`   | Wasm Wars gameplay             |
| `plasma-cube.jpg` | Plasma Cube                    |

Original photographs are kept locally in the ignored `raw/` directory and are
not part of the repository.
